LeetCode in Rust

From C to Rust, one problem at a time. Full IDE support, auto-generated tests, and a workflow that gets out of your way.

git clone https://github.com/ihibti/leetcode-rust.git && cd leetcode-rust && ./lc setup ⎘
~/leetcode-rust

Everything you need

🔗

Paste a URL, start coding

Run cargo solve <url> with any LeetCode link. It fetches the problem, generates the impl skeleton and test cases from the examples.

🧪

Real tests, not stubs

Auto-generated tests call your actual method with the example inputs. Just fill in the implementation and watch them go green.

📚

C-to-Rust guides

Syntax quick reference, side-by-side patterns, and a neetcode roadmap. Written for people who think in pointers and malloc.

📈

Track your progress

Archive solutions with difficulty and tags. cargo progress shows your stats, concept coverage, and weak spots over time.

⚙️

Full rust-analyzer

Completions, docs on hover, inlay hints, go-to-definition. The web editor can't compete with a real IDE setup.

🤖

AI tutor ready

Pre-configured for Claude Code, Cursor, and Copilot. The AI knows you're learning Rust from C and adapts its explanations.
